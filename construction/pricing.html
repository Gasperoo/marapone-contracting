// The question everybody asks second

YOU DON'T NEED TO
HIRE AN ENGINEER.

"We get the source code" usually lands as a liability — as if owning it means budgeting for a developer at six figures just to keep the thing alive. It doesn't, because of what is actually inside the bundle.

It ships as a normal installer. There is no Python to install, no Docker, no runtime for your IT department to keep patched, and no server to administer. On day one nobody needs to open the code at all — and the things you are most likely to want changed aren't code in the first place.

When you do want a change that is real development — a new report, an extra rule, a different export layout — it is ordinary Python and one HTML file. Any competent contract developer can read it. Nothing is obfuscated, nothing is a proprietary framework, and no licence forbids somebody else from touching it.

See the exact stack → What ownership does and doesn't cover

No engineer needed for any of this

  • ▸Rates, fees and tax tables — JSON files, edited in the app
  • ▸Scope checklists and house clauses — data, not code
  • ▸Swapping to a different market — a data edit
  • ▸Backup and restore — copy one SQLite file
  • ▸Installing it — a normal installer, on a normal laptop

Standard parts, on purpose

  • · Python — the most widely known language there is
  • · PyQt6 for the window; HTML/JS for the interface, no build step
  • · SQLite for storage — one open file, readable by anything
  • · A local GGUF model file you can swap for another
  • · PyInstaller bundles it, so Python is inside the app

Deliberately boring choices. The point of owning something is being able to hire anyone to work on it — which only holds if it is built out of parts people already know.

The honest limit

Owning the source doesn't make the software maintain itself. Operating systems move on, and in three or five years somebody will need to spend a day on dependencies and a rebuild. Ownership means that day is scheduled by you and can be done by anyone — not that it never comes.
