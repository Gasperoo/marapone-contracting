// Before you ask IT

IT RUNS ON THE LAPTOP
YOU ALREADY HAVE.

Full spec table →

Do I need a GPU?

No.

Everything runs on the CPU. A graphics card only makes big drawing sets finish faster — it is never required.

What machine?

A mid-range business laptop.

Apple Silicon (M1 or newer), or an Intel i5 / Ryzen 5 from the last few years, with 16 GB of memory. 32 GB is nicer for heavy days.

Which operating system?

Windows, macOS or Linux.

A normal installer. No Python to install, no Docker, no server to administer — IT is not being handed a project.

Internet?

Not needed to run it.

Works with the wifi off and can run fully air-gapped. Nothing about your drawings leaves the machine.

No hardware that fits? A dedicated local machine is an optional $1,000 add-on — sourced, configured, pre-loaded with your build and yours to keep. Or tell us what you're running and we'll confirm it on the free assessment.
